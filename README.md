# Next.js Admin Dashboard

A modern, responsive admin dashboard built with **Next.js, TypeScript, Tailwind CSS, and shadcn/ui**.

This dashboard provides a clean and flexible foundation for building modern web applications, admin panels, SaaS platforms, analytics dashboards, and management systems.

![Dashboard Screenshot](https://raw.githubusercontent.com/Astroashutosh/nextjs_dashboard/main/media/dashboard.png)

## ✨ Features

- Built with Next.js 16 and TypeScript
- App Router architecture
- Tailwind CSS v4
- shadcn/ui components
- Fully responsive design
- Light and dark mode
- Customizable theme presets
- Collapsible sidebar
- Flexible content layouts
- Authentication screens
- Dashboard layouts
- CRM dashboard
- Finance dashboard
- Analytics dashboard
- Productivity dashboard
- E-commerce dashboard
- User management
- Role management
- Kanban board
- Tasks management
- Invoice management
- Calendar
- File manager
- Chat interface
- Email interface
- Profile management
- Data tables
- Form validation
- Configurable UI
